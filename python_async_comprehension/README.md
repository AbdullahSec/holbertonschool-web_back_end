# Python - Async Comprehension

This project explores asynchronous generators, asynchronous comprehensions, and concurrent coroutine execution in Python.

## Learning Objectives

- Understand asynchronous generators and the `yield` statement.
- Iterate over an asynchronous generator with `async for`.
- Build a list using an asynchronous comprehension.
- Run coroutines concurrently with `asyncio.gather`.
- Measure elapsed time with the `time` module.

## Files

| File | Description |
| --- | --- |
| `0-async_generator.py` | Defines an asynchronous generator that yields random numbers. |
| `1-async_comprehension.py` | Collects values from an asynchronous generator using an async comprehension. |
| `2-measure_runtime.py` | Measures the runtime of four concurrent asynchronous comprehensions. |

## Requirements

- Python 3.8
- All Python files use type annotations and docstrings.
- All Python files are executable.
