# Python - Async

This project introduces asynchronous programming in Python using `asyncio`.
It covers coroutines, tasks, concurrent execution, and measuring runtime.

## Learning Objectives

- Understand `async` and `await`.
- Run asynchronous programs with `asyncio`.
- Execute coroutines concurrently.
- Create and work with `asyncio.Task` objects.
- Use the `random` and `time` modules.

## Files

| File | Description |
| --- | --- |
| `0-basic_async_syntax.py` | Defines a coroutine that waits for a random delay. |
| `1-concurrent_coroutines.py` | Runs multiple random-delay coroutines concurrently. |
| `2-measure_runtime.py` | Measures the average runtime of `wait_n`. |
| `3-tasks.py` | Creates and returns an `asyncio.Task`. |
| `4-tasks.py` | Runs multiple task-based coroutines concurrently. |

## Requirements

- Python 3.8
- All Python files use type annotations and docstrings.
- All Python files are executable.
